# TODO LIGHT

Windowsデスクトップに常駐する、半透明ガラス風の Todo ガジェット。親子タスク・先行関係(完了順の制約)・期限の管理。

> **個人用ツールです。** 自分が使うために作っており、更新は不定期です。Issue・Pull Request への対応や動作の保証はできません。[MIT ライセンス](LICENSE)のもと、自由に fork・改変して使ってください。

## ダウンロード

[Releases](../../releases) から最新の `TodoGadget-<バージョン>.zip` を取得する。リポジトリを clone した場合は `scripts\dist.bat` で同じ ZIP を作れる。

## 動作要件

- Windows 11(アクリル/マイカ背景は 22H2 以降。それ以前は透過ガラスで動作)
- Node.js は不要(初回と Electron の更新時のみ、Electron 約160MBを自動ダウンロードするためネット接続が必要)

## セットアップ

1. ZIPを好きな場所に展開(例: `C:\Tools\TodoGadget`)
2. `TodoGadget.bat` をダブルクリック
   - 初回のみ Electron を `%LOCALAPPDATA%\TodoGadget\runtime` にダウンロードする。ZIPを展開し直しても再ダウンロードされない
   - 新しいバージョンで Electron が更新されている場合は、アプリを終了してから `TodoGadget.bat` を実行し直すと取得し直す(起動中の場合は、その旨を表示して中止する)
   - ダウンロードした Electron は、`TodoGadget.bat` に埋め込んだ SHA-256 と照合してから展開する。一致しない場合は実行せず中止する(ハッシュは Electron 公式の `SHASUMS256.txt` と同じ値)
   - 以降は `%LOCALAPPDATA%\TodoGadget\runtime\TodoGadget.exe` を直接起動してもよい
3. SmartScreen が出たら「詳細情報」→「実行」(自作・未署名のため)

### スタートアップ登録

- `AddToStartup.bat` で登録、`RemoveFromStartup.bat` で解除。フォルダを移動したら再実行
- トレイアイコン右クリックの「ログイン時に起動」でも登録できる(どちらか一方でよい)

## 使い方

### 基本操作

- 上の入力欄に書いて Enter で追加 / 四角で完了 / ダブルクリックで編集
- ヘッダーをドラッグで移動、フチでリサイズ
- 「–」で隠す → タスクトレイのアイコンで再表示
- 見た目(透過度・ベース色・背景・最前面)は、ヘッダーの「外観」ボタンで変更する(下の「外観」を参照)
- トレイ右クリック: 表示/非表示、タイトルバーだけにする、位置、サイズ、背景、常に最前面、ログイン時に起動、終了

### 親子関係

- 左端のドットのグリップ(6点)をつかんで、別タスクの「中央」に落とす → 子タスクになる
- 別タスクの「上端 / 下端」に落とす → その前 / 後ろに並べ替え(同じ階層)
- リストの空き部分に落とす → 最上位に戻る
- ホバーで出る「＋」ボタンで子タスク追加、左向き矢印のボタンで親から外す
- 親の左の矢印(▸/▾ の山形)で折りたたみ。親には子の進捗 (2/5) が出る
- 親を完了にすると子もすべて完了になる

### 先行関係

- タスクにホバーして出る「リンク」ボタン(丸2つを線でつないだ形)をつかんで、「後続にしたいタスク」に落とす
  - 例: 「設計」のリンクボタンを「実装」に落とす → 設計が終わるまで実装は鍵マーク付きでブロック
- ブロック中のタスクは完了にできない(揺れて警告)
- 後続側には「先行 タスク名」のチップが出る。チップ内の × で解除
- ホバーすると先行タスクが黄色、後続タスクが緑でハイライトされる
- 循環(A→B→A など)になる指定は自動で拒否される

### 期限

- タスクにホバーして出るカレンダーボタン、または期限チップをクリックして日付を選ぶ(解除もそこから)
- 期限の**7日前から行が赤くなり始め、近づくほど濃く**なる。期限切れは最も濃い赤とチップ強調(例: 2日超過)
- 期限はその日の終わりまで有効。完了したタスクは赤くならない
- 日が変わっても、開きっぱなしのまま1分ごとに自動で更新される

### タイトルバーだけにする(最小化)

- ヘッダーの山形(⌃)のボタン(または `Ctrl + Alt + M`)で、タイトルバーだけの細い帯になる。完了数 (1 / 9 完了) を表示したまま、アプリは終了せず常駐
- もう一度押すと元の大きさに戻る。「–」はトレイへ隠す操作で、こちらとは別

### 位置とサイズの瞬間切替

ガジェットが見えなくなったとき、画面の隅へすぐ呼び戻せる。

- ヘッダーの配置ボタンを押すと「ミニ画面」が開く。現在の位置が縮小表示され、隅をクリックするとそこへ瞬間移動する(ホバーで移動先を点線でプレビュー)。小・中・大もここで切り替える。選ぶとポップアップは自動で閉じる
- どのアプリを使っていても使える**グローバルショートカット**(隠れていても、押すと手前に出る)

| キー | 動作 |
|---|---|
| `Ctrl + Alt + Q` / `E` | 左上 / 右上へ移動 |
| `Ctrl + Alt + Z` / `C` | 左下 / 右下へ移動 |
| `Ctrl + Alt + 1` / `2` / `3` | サイズ 小 / 中 / 大(最寄りの角を固定したまま変更) |
| `Ctrl + Alt + Space` | 表示 / 非表示 |
| `Ctrl + Alt + M` | タイトルバーだけにする / 元に戻す |

- トレイ右クリックの「位置」「サイズ」メニューからも同じ操作ができる
- 起動時、保存位置が画面外(モニター構成の変更など)なら自動で画面内に戻す
- 他のアプリが同じキーを使っていて登録できない場合は、自動で `Ctrl + Alt + Shift + キー` に切り替える(サイズ指定の数字キーは、テンキーの `Ctrl + Alt + Num1〜3` でも使える)。実際に割り当たったキーは配置ポップアップ(とトレイのメニュー)に表示され、どの候補も使えなかったキーは「–」になる
- 割り当て結果は `%APPDATA%\Todo Gadget\shortcuts.log` にも記録される

### 外観

ヘッダーの「外観」ボタン(半分塗りの円)でポップアップを開く。

- **透過度**: スライダー(0〜85%)で背景の透け具合を調整
- **ベース色**: 9色のパレット(ネイビー・ブラック・スレート・インディゴ・パープル・ワイン・ココア・フォレスト・ティール)から選ぶ。右端の虹色の丸でOSのカラーピッカーから好きな色を選べる(文字が読めるよう、暗めの色に自動で補正される)。即時に反映され、次回起動後も保持される
- **背景**: ガラス / アクリル / マイカ(Windows 11 のみ)。切り替えるとアプリが再起動する
- **常に最前面**: ON/OFF(トレイメニューとも連動)
- 設定とタスクは自動保存(`%APPDATA%\Todo Gadget\todo-data.json`)

## アンインストール

1. トレイアイコン右クリック →「終了」
2. `RemoveFromStartup.bat` を実行(スタートアップ登録をしていた場合)
3. 展開したフォルダを削除
4. 必要に応じて次も削除する
   - `%LOCALAPPDATA%\TodoGadget`(ダウンロードした Electron)
   - `%APPDATA%\Todo Gadget`(タスクと設定。**消すとタスクも失われる**)

## プライバシー

通信は初回の Electron ダウンロードのみ。タスクや設定は外部へ送信せず、ローカルの `todo-data.json` にだけ保存する。
